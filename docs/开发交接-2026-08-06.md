## 2. 当前架构与请求链路

```text
客户端
  │
  ├─ HTTP  :18080
  └─ HTTPS :18443
       │
       ▼
JingShield Go 进程
  ├─ /admin/       Vue 管理控制台
  ├─ /api/v1/      Session + CSRF 管理 API
  ├─ /openapi/v1/  X-API-Key 设备联动 API
  └─ 其他路径       WAF 防护链
                      │
                      ├─ IP/CC/验证/SQL/XSS/自定义策略
                      ├─ 拦截：HTML 或 JSON + event_id
                      └─ 放行：按 Host 转发到站点 upstream
```

主入口为 `cmd/jingshield/main.go`，支持：

- 默认启动：`jingshield -c <config>`
- 数据库迁移：`jingshield migrate -c <config>`
- 初始化管理员：`jingshield init -c <config> --username <name>`
- 测试证书生成：`jingshield cert --cert <path> --key <path> --hosts <hosts> --days 10950`

## 3. 今日完成内容

### 3.1 可运行入口与部署

- 完成 Go 主程序启动、迁移、初始化及证书子命令。
- 根目录保留两个生产部署脚本：
  - `run.sh`：首次安装、配置、迁移、初始化、证书和 systemd 管理。
  - `upgrade.sh`：校验候选二进制、迁移、备份、原子替换、失败回滚。
- Python 部署工具使用项目 `.venv`，SSH 密码只从 `JINGSHIELD_SSH_PASSWORD` 环境变量读取。
- Linux/Go/Python 构建支持根据网络环境选择官方源或国内镜像，不修改全局配置。
- Windows 构建脚本采用：

```powershell
go build -ldflags "-s -w -H=windowsgui" -trimpath -o bin/jingshield-windows-amd64.exe ./cmd/jingshield
```

- 测试证书支持 30 年有效期，仅定位为测试用途；生产必须替换为受信任证书。

### 3.2 反向代理与防护站点

- 支持精确 Host 和通配 Host 的多站点路由。
- 支持站点新增、编辑、启停、删除、上游地址、`pass_host` 和上游 TLS 校验选项。
- 存在站点配置后，未知 Host 返回 HTTP 421，避免误转发到默认源站。
- WAF 读取请求体后会恢复 `Body` 和 `GetBody`，源站仍能收到完整请求体。
- 请求体有最大尺寸限制，避免大包耗尽内存。
- 仅从配置的 `trusted_proxies` 信任转发头；非可信来源不能伪造真实客户端 IP。
- 修复同源 CORS 转发：仅当客户端 Origin 与公开 WAF 的 scheme/host 完全一致且站点不透传 Host 时，才将 Origin 改写为上游 Origin；外部或 `null` Origin 不改写。

### 3.3 防护与验证闭环

- IP 白名单、永久黑名单、临时黑名单。
- CC 请求频率、URL 频率、请求间隔、变异参数和穿盾行为检测。
- 8 种验证模式及签名验证 Cookie。
- SQL 注入、XSS 基础特征检测已运行。
- 自定义规则支持 `block` 与 `log` 动作和热加载。
- QQWry 为可选数据文件；缺失时归属地能力降级，不阻断主服务。

当前 SQL/XSS 仍以 RE2 特征检测为主，不应对外宣称已经实现通用语义 WAF。

### 3.4 策略中心与规则包

- 支持创建、编辑、启停、删除自定义策略。
- 支持上传 JSON 规则包，限制如下：
  - 只接受 `application/json`。
  - 最大 2 MB。
  - 使用严格 JSON 解码，拒绝未知字段和多个顶层 JSON 值。
  - 原始上传文件不落盘，事务导入规则。
- 支持 HTTPS 在线更新、版本状态、Ed25519 签名校验。
- 在线更新拒绝带用户信息的 URL，并拒绝解析到私网、回环、链路本地、未指定或组播地址，降低 SSRF 风险。
- `rules/packs/jingshield-baseline-2026.08.json` 已补充 Tomcat、Fastjson/JNDI 等应急特征。
- 被保护业务的 multipart 上传已具备基础文件名、声明 MIME、检测 MIME、类型不一致和有限内容样本检查。

仍未完成压缩炸弹、递归归档、完整恶意文件扫描和沙箱分析。

### 3.5 攻击事件运营

- 风险等级扩展为：严重、高危、中危、低危、信息。
- 使用服务端分页，单页上限 100。
- 支持攻击类型、IP、严重度、时间范围和事件编号筛选。
- CSV 使用流式导出，避免一次性加载大数据；对公式型单元格做前缀转义，防止表格公式注入。
- 攻击日志保存脱敏、限长请求报文：
  - Authorization、Cookie、密码、Token、API Key 等敏感值自动脱敏。
  - 报文最大 32 KB，超长截断。
- 每次请求生成 `JS-...` 事件编号。
- `jyj_attack_event_ref` 保存历史事件编号到聚合攻击日志的映射，后续聚合不会让历史编号失去查询关系。

已知边界：攻击日志按“同 IP、同类型、同一天”聚合，聚合行保存的是最近一次请求报文；历史事件编号可以反查聚合记录，但尚未为每个编号保存独立报文快照。

### 3.6 安全拦截页

- 普通浏览器导航命中时返回鲸盾深色拦截页。
- 页面展示：事件编号、泛化风险类型、拦截时间、联系信息。
- `/api`、`/openapi` 和 XHR 命中时仍返回 JSON，并包含 `event_id`。
- 不向客户端展示规则名、正则表达式、命中载荷或内部判定详情。
- 增加 CSP、`no-store`、`nosniff`、禁止 iframe 嵌套和无 Referrer 等响应头。
- 联系信息通过动态配置 `security_contact` 管理。

线上验证样例：

- HTTP 状态：403
- 风险显示：请求安全风险
- 页面编号已写入事件索引并关联聚合攻击记录
- 测试规则名和测试载荷未出现在响应正文

- 登录页不预填用户名。
- 用户管理支持多管理员、启停、密码重置和首登强制改密。
- favicon 已提供 SVG、PNG 和多尺寸 ICO：

### 3.8 安全设备联动 API

已实现独立 `X-API-Key` 鉴权，不复用管理 Session：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/openapi/v1/status` | 读取节点和站点健康状态 |
| POST | `/openapi/v1/ip/block` | 永久或临时封禁 IP |
| POST | `/openapi/v1/ip/unblock` | 解除 IP 封禁 |
| POST | `/openapi/v1/events/{format}` | 接收设备安全事件 |

事件格式包括 CEF、LEEF、Suricata、Wazuh 和通用 JSON。API Key 支持轮换且只在生成时完整显示一次。

## 9. 已知边界和待办

按优先级建议：

1. **整理 Git 提交范围。** 当前工作区存在大量未提交修改、旧构建 hash 删除和新构建文件，禁止直接执行无审查的 `git add -A`。
2. **恢复根 README 入口。** 当前 `README.md` 处于删除状态，仅有 `README_EN.md` 和 `README_CN.md`；按要求应让根 `README.md` 默认展示英文并链接中文版本。
3. **重新构建 Windows 包。** 当前 Windows 二进制未包含最后一轮事件索引、拦截页和 favicon 变更。
4. **补日志保留执行器。** 已有 `log_keep_days` 配置，但尚未发现自动清理攻击/访问日志及事件编号索引的后台任务。
5. **事件级证据快照。** 当前历史 `event_id` 映射到聚合行，若客服需要还原每次请求，应在事件索引表增加独立时间、风险、脱敏报文快照或拆分冷热存储。
6. **语义检测 P0。** 优先实现规范化管线、路径穿越、SSRF URL 和 XXE 流式解析，再进入 SQL/XSS 上下文评分。
7. **文件上传增强。** 增加归档递归深度、解压比、魔数库、活动内容检测和可选外部扫描器。
8. **TLS 生产化。** 当前为单张静态证书；多站点 SNI、ACME、证书到期告警未实现。
9. **多节点状态。** Redis 端口已规划，但共享限速、验证状态、策略广播和节点聚合仍未实现。
10. **账号体系。** 当前没有细粒度 RBAC、MFA、OIDC/SAML。
11. **前端性能。** 拆分 Dashboard/ECharts 大 chunk，并补浏览器端视觉回归；本次因自动化浏览器实例不可用，仅完成真实 HTTP 与资源级验证。
