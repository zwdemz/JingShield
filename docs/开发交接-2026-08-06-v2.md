## 2. P0 语义分析底座

### 2.1 架构设计

```text
请求参数（query/form/cookie/header/path/body）
       │
       ▼
  normalize.Pipeline（有界多层解码）
    ├─ DecodeURL        %XX + %uXXXX + 0xXX（仅可打印 ASCII）
    ├─ DecodeHTML       命名实体 + 数字实体
    ├─ NormalizeUnicode  NFKC + 全角→半角
    ├─ StripZeroWidth    U+200B~U+200F, U+FEFF 等
    └─ CollapseWhitespace
       │
       ▼ 规范化后的值
    ┌──────────────────────────────────────┐
    │ DetectPathTraversal   → ../ 绝对路径   │
    │ DetectSSRF            → 内网/元数据 IP  │
    │ DetectXXE             → DTD/ENTITY     │
    └──────────────────────────────────────┘
       │
       ▼ detector.Result
    Engine.Evaluate() 步骤 8/9/10
```

核心原则：

- **有界解码**：最大 5 轮迭代，收敛后停止，防止 ReDoS 和 CPU 耗尽
- **来源追踪**：每个参数值保留 Source（query/form/cookie/body/header/path）
- **大小限制**：规范化输出最大 8192 字节，超长截断并标记 Truncated
- **幂等收敛**：连续两轮解码结果相同时停止

### 2.6 已知边界

- 当前语义检测器基于规范化后的字符串模式匹配，**不是** tokenizer/AST 级别
- SQL 语义（tokenizer + 评分引擎）和 XSS 上下文语义（HTML/JS/URL 上下文 tokenizer）属于 P1 阶段
- SSRF 检测不含 DNS Rebinding 防护（需要运行时 DNS 查询）
- XXE 检测基于文本扫描，不解析完整 DOM（设计意图：保持流式、低开销）
- 规范化管线对 `0x` 前缀仅解码可打印 ASCII（0x20~0x7E），避免破坏 URL 中的数值编码 IP 格式

## 3. 一键部署脚本 `install.sh`

### 3.1 设计思路

参照雷池 SafeLine 的 `bash -c "$(curl -fsSLk ...)"` 模式，采用两阶段架构：

```
bash -c "$(curl -fsSLk https://release.jingshield.example/install.sh)"
         │
         ▼
install.sh（bootstrap，~230 行）
  ├─ banner + 彩色输出
  ├─ 环境检测：root / Linux / systemd / curl|wget / sha256sum
  ├─ 架构检测：uname -m → amd64 | arm64
  ├─ 发行版检测：/etc/os-release → apt/dnf/yum/apk
  ├─ MySQL 客户端：缺失时自动安装（交互式询问 / 非交互直接装）
  ├─ 已安装检测：发现 /opt/jingshield 时询问是否覆盖
  ├─ 下载完整包：tar.gz + .sha256
  ├─ SHA-256 校验
  ├─ 解压到 /tmp/jingshield-install.XXX（trap EXIT 自动清理）
  └─ exec bash run.sh "$@" → 调用已有的完整安装逻辑
```

### 3.2 用法

```bash
# 一行安装（最新版本）
bash -c "$(curl -fsSLk https://release.jingshield.example/install.sh)"

# 指定版本 + 管理员
curl -fsSLk .../install.sh | bash -s -- --version 0.2.0 --admin-user myadmin

# 远程数据库
curl -fsSLk .../install.sh | bash -s -- --skip-db-provision --secrets-file /tmp/db.values

# 自定义安装目录
curl -fsSLk .../install.sh | bash -s -- --install-dir /srv/jingshield
```

### 3.3 支持的发行版

| 发行版 | 包管理器 | MySQL 客户端安装命令 |
|--------|----------|---------------------|
| Ubuntu / Debian | apt | `apt-get install -y mysql-client` |
| CentOS / RHEL / Rocky / Alibaba / Anolis | yum/dnf | `yum install -y mysql` |
| Alpine | apk | `apk add --no-cache mysql-client` |

### 3.4 与雷池对比

| 对比项 | 雷池 SafeLine | JingShield |
|--------|--------------|------------|
| Bootstrap | shell → Python | shell → shell (run.sh) |
| 运行时依赖 | Docker + docker-compose | MySQL + systemd |
| 架构检测 | Python 内判断 | shell `uname -m` |
| 完整性校验 | Python 内部 | sha256sum + 独立 .sha256 文件 |
| 临时目录 | `/tmp/safeline.py` | `mktemp -d` + trap 自动清理 |
| 参数透传 | `"$@"` | `FORWARDED_ARGS` 数组 |
